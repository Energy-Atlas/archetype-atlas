# ADR 0014: Effective reviewed membership and construction applicability

Date: 2026-10-07. Status: accepted.

Reviewed programs replace source leaves individually. Composition must start
with the complete source context and substitute available overlays. Member source
IDs, represented areas and weights are invariant between source and reviewed
recipes. An absent overlay means unchanged source semantics, never a missing
member or a new denominator.

Shared constructions have source-derived applicability relationships referencing
construction packages. Preserve correlated building, template and climate context,
source space type and element role without cloning physical definitions or
claiming every Cartesian combination. Office package scope expands only to the
selected source office families; Any remains explicit. Physical comparison ignores
applicability and source-package metadata. Generic internal/ground fallbacks retain
their explicit building-level policy and do not acquire fabricated contexts.

Delivery v2 indexes carry filter metadata per record and packet membership.
Reviewed replacement precedes exact filtering and projection. Superseded source
IDs are not aliases for reviewed IDs. Impossible scalar filters fetch no packets.
This extends the initially unpublished v2 schema; v1 is unchanged.

The immutable initial definition freeze v0.1.0 is superseded, not rewritten.
Corrected v0.1.1 includes the counted-area source default lock. Current validators
check root version, SI unit vocabulary, physical/schedule bounds and nested foreign
keys, including ancillary equipment schedules. The old freeze remains an audit
artifact and is not advertised as a valid consumer release.
