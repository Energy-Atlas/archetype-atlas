# ADR 0031: Apartment fixed native source associations

Accepted 2026-10-15 for the bounded A3 proof producer. Public apartment runtime
admission, caller control bindings and selected dwelling timing admission remain
separate A4 work.

The 90 fixed Ruleset IDs retained by the original 84 programme/view definitions
are 46 genuinely named c8 upstream schedules and 44 explicit reviewed constant-zero
overlays. The latter are 42 reviewed gas-equipment absences and two reviewed DOE
corridor occupancy zero resolutions. Earlier shorthand calling all90 original c8
named schedules is incorrect. Keep the entire90-ID denominator, exact original
SourceObjects and their distinct authority. Original source-view gas unknowns
remain unknown. An overlay's internal `source_index:0` never selects the unrelated
upstream `Always Off` row.

Construct the 46 named schedules with exact pinned c8 `model_add_schedule` and
entire original rows, in source order. Construct each44 reviewed zero overlay's
native representation with the exact c8 `create_constant_schedule_ruleset(0)` and
its original resolution name. Retain the unchanged original Default-only rule,
2000 dates, absent explicit special-day selectors and whole reviewed provenance.
Record actual constructed default/design-day/getter state separately; it does
not retroactively supply upstream special-day metadata or upstream equivalence.

Use exact c8 constructors, water helpers, table rows and `standard.rb` lookup at
OpenStudio3.10, with the distinct actual Standards0.8.6 `information.rb` getter.
This explicitly disclosed hybrid is not all-c8 native equivalence. Whole member
hashes, revisions, original retrieval receipts, both upstream notices, immutable
capture code and before/after source/runtime manifests accompany retained native
inputs and outputs. The actual lexical `3.10.0 < 3.8.0` getter branch and round5
policy remain unchanged. Ordinary verification reads retained bytes offline and
never recaptures, downloads or installs a runtime.

The20 original per-area water paths link40 source/reviewed alternatives and eight
static family/template/calendar pools. The80/120m2, multiplier1 spaces are explicit
synthetic caller probes. Neither source geometry, fixture multiplicity, allocation,
heater/loop energy nor full-prototype registration follows from them. Keep the
original140F source operand, actual native conversion/stored Celsius and getter
values separate; constructor fractions0.2/0.05 remain control evidence.

Derived proof files have their own paths and whole-file SHA256 values. The existing
Core4 strict requirement, association, controls, per-ID qualification and static
pool shapes remain unchanged. Each40 per-ID qualification has exactly one
`native_control_schedules` FieldEvidence entry. Its `original_value` is the
complete control compilation and equals the value at `/native_control_schedules`
in the separate exact canonical preimage `{"native_control_schedules":value}`.
Construct its SourceObject outside those bytes. No file contains its own hash or
qualification. A separately hashed resource manifest covers complete resources.
Validate every static pool member, including unselected alternatives.

These fixed/getter/control proofs do not qualify selected HMM timing, create
per-ID timing-ready flags, modify source definitions or open any production
selector. R44's mandatory one LOAD plus three source CONTROL schedules belongs to
the explicit unpublished caller mode; A4 implements that obligation using these
independent source proofs, without a water-only erasure fallback.
