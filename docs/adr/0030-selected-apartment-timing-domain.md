# ADR 0030: Locked selected apartment timing domain

Status: bounded A1 component decision. Apartment production selection and programme qualification remain closed.

The selected dwelling occupancy and interior-lighting method receives only the 2007 non-leap local-standard calendar, positive integer resident count, USPS state, latitude, longitude, physical UTC offset, explicit source unit seed and a verified ResourceSet. The timing domain is the exact 37 ordered four-field tuples in positive M1 then R1 native capture encounter order. It is stored as schema-versioned canonical JSON at `data/schedule-generator/apartment/timing-domain.json`. Numeric coordinate equality admits integer or float representations; the tuple cannot be recombined field by field. These locations are controlled native arguments, not stock prevalence, DOE geography, prototype defaults or a basis for arbitrary weather choice. N=0 has a distinct source skip contract and never enters the selected positive method or source streams.

Each location record retains its original native case and input field pointers, raw values and units, source revision and capture SHA-256, extraction date, exact transformation and interpretation. The corresponding timing lock pins both native vectors and reference locks, the source archive and lock, the durable domain bytes, and the 32 selected residential resource record hashes. The isolated build producer recompiles those 32 records from unchanged verified ResStock archive members, adds only the domain reference record, then uses the normal resource writer and ResourceSet constructor. Its new resource identity is independent of the installed M1 data. The record and manifest retain the upstream ResStock notice path.

The selected method calls the existing source activity kernel once, retains its stream reservation and transient resident states for source arithmetic, and returns exactly two 8,760-hour channels plus a compact source receipt. Existing whole residential wrappers still use their original weather and installed-equipment inputs. No production recipe, selected adapter, public qualifier or annual magnitude is created by this component.

The archived target inventory contains 58 positive channel pairs. Fifty-five use genuine unmodified activity trajectories (six M1, 45 R1 and four selected-method probes). R1 cases 49–51 are separate controlled component probes: the pinned native harness completes real activity draws and then substitutes specified resident-state matrices before shape generation. Their arrays are compared through the same selected shape arithmetic with a test-local replay of that documented capture protocol. They are not same-argument full activity realizations and cannot justify a production state override.
