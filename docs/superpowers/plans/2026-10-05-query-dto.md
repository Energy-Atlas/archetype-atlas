# Generic query delivery implementation plan

> **For agentic workers:** Use superpowers:executing-plans task by task.

**Goal:** Publish generic bounded static data lookup and a complete consumer contract.

**Architecture:** Frozen tables produce indexed immutable JSON packets. A reference
resolver filters and projects locally. MkDocs publishes the same artifacts that a
future query service can implement semantically.

**Tech stack:** Python 3.11+, standard library, existing pinned jsonschema/MkDocs.

**Spec:** ../specs/2026-10-05-query-dto-design.md

## Global constraints

- Branch `feature/query-dto`; no main merge or BEMGen edits.
- Generic SI fields; schema 1.0.0; canonical archives remain unchanged.
- Explicit source/reviewed view, no inferred zero, no default variant/calendar.
- Hash-bound dependencies, lazy schedules/evidence, deterministic publication.
- User authorizes autonomous execution and live publication; no routine pauses.

## Review focus

Corrupt manifest/resources; source variants with identical labels; climate-unknown
systems; annual calendar loss; water attribution mistaken for physical gains.
These cases are exercised in Tasks 1–3.
