Execute the tasks in order, with one production writer and independent specification/code review at each gate. Checkboxes track future work. This is a planning handoff; it authorizes no production edit, native run, source retrieval, release, Git mutation, or deployment.

**Goal:** Ship the complete, source-faithful SuperMarket Task 10 family across five alternative templates, both SOURCE and REVIEWED programme views, all 40 compositions, and one once-owned absolute main-water fixture per selected source case.
